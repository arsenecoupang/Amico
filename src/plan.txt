📋 프로젝트 개요
학교 환경에서 친구 사귀기와 대화 시작을 돕는 반응형 웹앱 "Amico"를 React + TypeScript + Tailwind CSS로 개발해주세요.



🚀 핵심 기능 요구사항


1. 인증 시스템
로그인/회원가입 탭 기반 인터페이스
회원가입 시 비밀번호 확인 검증 (6자 이상, 일치 여부)
데모 모드 지원 (서버 연결 실패 시 자동 전환)
온보딩 프로세스 (닉네임, 성격, 취미, MBTI, 그룹 설정)


2. 메인 대시보드
사용자 프로필 표시
최근 대화 목록
친구 추천 카드
빠른 액션 버튼들


3. 매칭 시스템
같은 그룹 내 사용자 추천
공통 관심사 기반 매칭
카드 스와이프 또는 버튼 기반 인터페이스


4. 실시간 채팅
1:1 채팅 기능
5초 이상 입력 없을 시 대화 주제 자동 추천
O/X 퀴즈를 통한 정보 공개 시스템
온라인 상태 표시


5. 칭찬 전달 시스템
익명으로 칭찬 보내기
받은 칭찬 확인하기


6. 프로필 편집
닉네임, 성격, 취미, MBTI, 그룹 수정
실시간 미리보기


🎨 디자인 시스템


색상 팔레트
```css
/* 파스텔 색상 (배경용) */
--pastel-pink: #ffe1e6;
--pastel-blue: #e1f0ff;
--pastel-green: #e8f5e8;
--pastel-purple: #f0e8ff;



/* 비비드 파스텔 (액센트용) */
--soft-pink: #ff8fa3;
--soft-blue: #74c0fc;     /* 메인 브랜드 컬러 */
--soft-green: #69db7c;
--soft-purple: #9775fa;   /* 그라데이션용 */
```



타이포그래피
```css
--font-size: 14px;                    /* 기본 크기 */
--font-weight-medium: 500;            /* 제목, 버튼, 라벨 */
--font-weight-normal: 400;            /* 본문, 입력 필드 */
```



브랜딩
로고: "Amico" 텍스트 + Sparkles 아이콘 (Lucide React)
그라데이션: #74c0fc → #9775fa
전체적으로 밝고 친근한 파스텔 톤


🏗️ 기술 스택 및 라이브러리


필수 기술 스택
```json
{
  "framework": "React 18 + TypeScript",
  "styling": "Tailwind CSS v4",
  "ui-components": "shadcn/ui",

  "backend": "Supabase (선택적)"
}
```



주요 라이브러리
UI 컴포넌트: Button, Card, Input, Tabs, Alert, Avatar 등
알림: 브라우저 푸시 알림 지원
상태 관리: React useState/useEffect hooks


📱 화면 구조 및 라우팅


화면 목록
LoginScreen: 로그인/회원가입--[o]
OnboardingScreen: 프로필 설정--[o]
MainScreen: 메인 대시보드
MatchingScreen: 친구 매칭
ChatScreen: 1:1 채팅
QuizScreen: O/X 퀴즈
ComplimentScreen: 칭찬 전달
ProfileEditScreen: 프로필 편집


네비게이션
좌하단 고정 네비게이션 버튼들
반응형 디자인 (모바일에서는 아이콘만, 데스크탑에서는 텍스트 포함)


🔧 주요 구현 세부사항


상태 관리
```typescript
type Screen = 'login' | 'onboarding' | 'main' | 'matching' | 'chat' | 'quiz' | 'compliment' | 'profile';



interface OnboardingData {
  nickname: string;
  personality: string[];
  hobbies: string[];
  mbti: string;
  group: string;
}
```



데모 모드
서버 연결 실패 시 자동으로 데모 모드로 전환
모든 기능이 로컬 데이터로 완전 작동
실제 서버 연결 없이도 앱의 모든 기능 체험 가능


알림 시스템
브라우저 푸시 알림 권한 요청
새 메시지, 매칭 알림 등
알림 클릭 시 해당 화면으로 이동


반응형 디자인
모바일 우선 설계
태블릿, 데스크탑 모든 해상도 지원
터치 인터페이스 최적화
